# 30-second demo script

The finished demo is generated by `demo/build_demo.py` from real app screenshots (`demo/capture_shots.sh`) and the release data: [video](https://aboodbasill.github.io/mars-eva-command/demo/Mars_EVA_Command_demo_30s.mp4), [slides](https://aboodbasill.github.io/mars-eva-command/demo/). The table below is the plan for a narrated version, if you record one.

| Time | Screen | Voice-over / caption |
|---|---|---|
| 0–4 s | Title bar, Jezero map | "Mars EVA Command — team ___, Space Apps 2026." |
| 4–9 s | EVA mode, route appears | "A crew at Jezero is 3 to 22 light-minutes from Earth. They must plan their own walk." |
| 9–19 s | Stations S1–S4 → depot; switch return budget 2 km → 10 km | "Real HiRISE terrain, real sample sites. The red dashes show that 45 % of this 6.7 km walk is beyond a 2 km return budget." |
| 19–23 s | Slope limit 20° → 15° (route lengthens by 0.2 km); data-confidence legend; Environment chart | "Every point says what supports it, and the weather is Perseverance's own." |
| 23–28 s | 3D simulator (`game/#play&at=S3&ltst=17.4`): walk a few steps, open the Map's Predictions tab | "Then rehearse it in 3D: oxygen and cooling from NASA EVA work rates, and a live return margin." |
| 28–30 s | End card with app and repo URLs | "Works offline. Not a certified route: a planning candidate." |

Rules: only show route changes that actually happen (20°→15° does). Never say "safe". Use dataset counts from `REFERENCES.md`.
